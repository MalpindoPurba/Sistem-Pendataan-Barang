Sistem Pendataan Barang

Deskripsi

Program sederhana menggunakan Python untuk membantu pengelolaan data barang.

Fitur

- Menambahkan barang
- Menampilkan daftar barang
- Mencari barang berdasarkan nama
- Menghapus barang

Teknologi

- Python
- GitHub

Cara Menjalankan

1. Pastikan Python sudah terpasang.
2. Jalankan file "main.py".
3. Pilih menu sesuai kebutuhan.

Tujuan

Proyek ini dibuat sebagai implementasi materi informatika untuk mempelajari pemrograman dan pengelolaan kode menggunakan GitHub.
